Firewall

For every listening port the network can reach, portop asks the host firewall whether incoming traffic gets through.

Verdicts

VerdictMeaning
allowedAnyone can connect, or no firewall is running
restrictedOnly some sources may connect
blockedIncoming connections are refused
?portop cannot tell

Loopback ports show -: the firewall does not matter for them.

What each system reports

SystemRead fromUnknown when
Linuxufw rules and default policy; firewalld's default zone (ports, services, target); an empty nftables ruleset means no firewallportop is not root (the tools refuse), or nftables input rules or firewalld rich rules apply
macOSThe application firewall's global stateIt is on but not blocking everything, since it decides per application
WindowsWindows Firewall profilesAny active profile is on, since rules are per program and slow to enumerate

Rules are read at most every 30 seconds. Turn the check off with --no-firewall or resolve_firewall: false.
