The table

One row per socket. Optional columns appear as the terminal gets wider; click a heading, or press s, to sort by it.

Columns

ColumnShows
PORTLocal port and its service name (:22 ssh), colored by exposure on listening rows.
PROTOTCP or UDP; 6 marks IPv6.
STATEThe TCP state. A bound, unconnected UDP socket is UNCONN and counts as listening.
PROCESSThe owning process; nginx +3 when three workers share the socket.
PID, CPUProcess ID and CPU use since the previous refresh.
REMOTEThe peer, or its reverse-DNS name, for established connections.
IFACEThe bind address; 0.0.0.0 and :: mean every interface.
FIREWALLThe host firewall's verdict for a port the network can reach.
PROJECTThe project and framework behind a listening port, storefront Next.js (details).
TRAFFICBytes per second received and sent, ↓1.2K ↑340, for an established TCP connection (details).
USERThe socket's owner.
CONTAINERDocker or Podman container, or namespace/pod/container on Kubernetes (details).
SYSTEMDThe systemd unit on Linux. On Windows it is SERVICE: the services hosted by the process.

Exposure

A listening port is colored by who can reach it, at any terminal width:

ColorBound toReachable from
Red0.0.0.0, ::Every network the host is on, unless a firewall blocks it
AmberOne addressThat interface's network (a LAN or container network)
Green127.0.0.1, ::1This machine only

Sorting by IFACE lists the most exposed ports first. The same scopes appear as "scope": "all" | "address" | "loopback" in JSON and drive baseline drift.

Mouse

Click to select, double-click for details, right-click for the kill confirmation, middle-click to open the port, scroll with the wheel, click a heading to sort and click it again to reverse.

Details

enter shows the command line, executable, working directory, user, memory, threads, open files, start time and, for a shared socket, its workers.

Stopping a process

k records the process's start time when the confirmation opens and checks it again just before sending the signal. If the process exited and its PID was reused in the meantime, the signal is refused. On Windows both choices end the process.
