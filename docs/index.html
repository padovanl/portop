What's really using your ports?

A terminal UI for TCP/UDP ports — like htop, but for ports. See the process, the systemd unit, the Docker container, and kill it, right from your keyboard.

Install portop View on GitHub
$ curl -fsSL https://raw.githubusercontent.com/padovanl/portop/main/install.sh | sh

Live demo — filter, inspect, confirm-before-kill, help. Recorded on a real terminal, not staged.

Everything ss and lsof leave out

They tell you what's bound to a port. portop tells you who, why, and lets you act on it.

▣

Live, color-coded table

LISTEN, ESTABLISHED and transient states are colored at a glance, with per-process CPU% sampled like top.

✕

Kill, safely

k then confirm — graceful SIGTERM or forced SIGKILL. Never a stray keypress away.

/

Instant filter/search

f and start typing — matches port, process name or PID as you type.

↗

Open in browser

o launches http(s)://localhost:PORT for the selected row — no more typing it by hand.

{}

systemd & Docker aware

Every row shows the owning .service unit and Docker container, resolved from cgroups — no extra daemons.

●

New-port alerts

Freshly opened listening ports are highlighted live, with an optional desktop notification (--watch-new).

±

Baseline drift detection

--save-baseline then --diff from a cron job — get a non-zero exit code the moment an unexpected port starts listening.

>_

Scriptable

--json prints a clean snapshot for piping into jq, dashboards, or your own tooling.

◆

Configurable

portop --init-config writes a template config.yml — pick a theme (dracula, nord, mono, ...) and remap any key.

Install

Pick whichever fits your workflow. Linux and macOS, amd64 and arm64.

curl installer

# detects OS/arch, verifies checksum
curl -fsSL https://raw.githubusercontent.com/padovanl/portop/main/install.sh | sh

Debian / Ubuntu (.deb)

# grab the .deb from the latest release, then
sudo dpkg -i portop_*_amd64.deb

Tarball (any Linux/macOS)

tar -xzf portop_*_linux_amd64.tar.gz
sudo install -m 755 portop /usr/local/bin/portop

From source

go install github.com/padovanl/portop/cmd/portop@latest

Keybindings

Everything's reachable in one keystroke. Full list is also in-app via ?.

enterprocess details — cmdline, exe, cwd, user, RSS, start time
kkill process — then y SIGTERM or f SIGKILL
oopen http(s)://localhost:PORT in the browser
f / /filter/search by port, process or PID
vtoggle IPv4 / IPv6 / both
eshow/hide ESTABLISHED connections
scycle sort column
ccopy selected row to clipboard
nclear the new-port highlight
qquit
