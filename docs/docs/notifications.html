    New-port alerts

    A port that starts listening while portop runs is marked in the table; --watch-new also raises a desktop notification.

    Marks

    New listening ports are highlighted until you press n. The first scan after start-up marks nothing.

    Desktop notifications

    SystemShown with
    Linuxnotify-send, when installed
    macOSNotification Center
    WindowsA toast shown as portop with its icon; Microsoft Store installs show it as Windows PowerShell

    Without a notifier nothing happens; the table still marks the port. Enable it permanently with watch_new: true.
