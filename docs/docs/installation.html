    Installation

    portop is a single static binary. Package managers keep it up to date; the release archives work anywhere.

    Package managers

    SystemCommandUpdates
    Debian, UbuntuAPT repositoryapt upgrade
    Linux with snapdsudo snap install portopautomatic
    macOS, Linuxbrew install portopbrew upgrade
    Windowswinget install padovanl.portopwinget upgrade
    WindowsMicrosoft Storeautomatic

    APT repository

    sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.lucapadovan.dev/lucapadovan.gpg | sudo tee /etc/apt/keyrings/lucapadovan.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/lucapadovan.gpg] https://apt.lucapadovan.dev stable main" \
  | sudo tee /etc/apt/sources.list.d/lucapadovan.list
sudo apt update && sudo apt install portop

    The signed repository at apt.lucapadovan.dev serves amd64, arm64 and armhf (the ARMv6 build, which also runs on ARMv7).

    Install script

    curl -fsSL https://raw.githubusercontent.com/padovanl/portop/main/install.sh | sh

    Linux and macOS. The script detects the architecture, verifies the release checksum and installs to /usr/local/bin, or ~/.local/bin when that is not writable. Set PORTOP_VERSION to pin a release, PORTOP_ARCH (amd64, arm64, armv7, armv6) to override detection, or PORTOP_INSTALL_DIR to choose the directory.

    Release archives

    Every release has .tar.gz archives (.zip on Windows) and, for Linux, .deb and .rpm packages:

    TargetRuns on
    linux_amd6464-bit x86 Linux
    linux_arm6464-bit ARM Linux (ARMv8.0)
    linux_armv732-bit ARM Linux with hardware floating point (VFPv3)
    linux_armv632-bit ARM Linux with VFP, including Raspberry Pi 1 and Zero
    darwin_amd64, darwin_arm64macOS on Intel and Apple Silicon
    windows_amd64, windows_arm64Windows 10 1809 or later, Windows 11 on ARM

    Choose the target of the installed operating system, not just the CPU: a 64-bit board running a 32-bit OS needs armv7 or armv6. Each published file has a build attestation; check one with gh attestation verify FILE --repo padovanl/portop.

    From source

    go install github.com/padovanl/portop/cmd/portop@latest

    macOS first launch

    Release binaries are not notarized. If macOS blocks a binary downloaded with a browser, run portop once, open System Settings → Privacy & Security and choose Open Anyway. Homebrew and the install script are not affected.
