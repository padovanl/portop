    Troubleshooting

    Rows without a process

    The socket belongs to another user. Run sudo portop on Linux and macOS, or use an Administrator terminal on Windows. TIME_WAIT rows never have one: the connection is closing and no process holds it.

    The firewall column shows ?

    The firewall could not be read or decides per program. See what each system reports; on Linux, run portop with sudo.

    No container names

    portop cannot reach the Docker or Podman socket. Check DOCKER_HOST, membership of the docker group, or run with sudo. On Kubernetes nodes, /var/log/containers must be readable.

    Washed-out colors

    The terminal reports 16 colors. Set TERM=xterm-256color or COLORTERM=truecolor.

    A kill is refused

    The process exited or was replaced since the row was shown; portop refuses to signal a different process. Refresh with r and try again.

    Reporting a problem

    Open an issue with portop --version, the operating system and, if useful, portop --json output.
