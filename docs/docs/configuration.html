    Configuration

    Everything is optional. Command-line flags win over the file.

    Settings screen

    Press , in the table to preview the 13 themes live and rebind any of the 20 actions. Changes are saved to the configuration file at once.

    config.yml

    portop --init-config writes a commented file in the OS configuration directory: ~/.config/portop/config.yml on Linux, ~/Library/Application Support/portop/config.yml on macOS, %AppData%\portop\config.yml on Windows. --config uses another.

    theme: tokyo-night        # default, dracula, nord, solarized, gruvbox, catppuccin,
                          # tokyo-night, monokai, darcula, vscode, ubuntu, rose-pine, mono
refresh_interval: 2s
show_established: true    # false behaves like --listen
resolve_dns: true
resolve_systemd: true
resolve_docker: true
resolve_firewall: true
resolve_traffic: true
watch_new: false
keybindings:
  kill: ["x"]
  quit: ["q", "ctrl+c"]

    Keybinding actions: up, down, page_up, page_down, top, bottom, enter, kill, open, filter, sort, protocol, established, new_mark, copy, refresh, help, quit, escape, settings. An unknown theme or action stops portop with the list of valid ones.
