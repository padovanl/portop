    Cockpit add-on

    The dashboard inside Cockpit, using its login and your permissions. Linux only.

    Install

    mkdir -p ~/.local/share/cockpit
cp -r cockpit/portop ~/.local/share/cockpit/portop   # from a portop checkout

    Open Tools → Ports (portop). portop must be installed on the host; the page calls portop --json, --inspect-pid and --signal-pid through Cockpit's bridge, so there is no extra service to expose. Installing it under /usr/share/cockpit/portop makes it available to every user.
